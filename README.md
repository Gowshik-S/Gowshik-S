### 🛠 What I'm building

**[QuillPrint](https://github.com/Gowshik-S)** — Live cloud print marketplace, running production across two campus vendor locations. Exactly-once job claiming, health-gated failover, two-phase verified physical completion. Self-hosted on OCI ARM64 behind Cloudflare Tunnel + Tailscale — zero open inbound ports.
`FastAPI` `PostgreSQL` `Redis` `Cloudflare Workers` `GitHub Actions → GHCR`

**[Rio Agent](https://github.com/Gowshik-S/Gemini-Live-Agent)** — Autonomous AI agent built for the Gemini Live Agent Challenge: one task in, completed end-to-end. ADK bidi-streaming orchestration on Cloud Run, paired with a local vision + voice loop (Silero VAD, RapidOCR, screen control).
`Gemini 2.5 Flash/Pro` `ADK` `FastAPI` `WebSocket` · 📦 PyPI: `rio-agent`

**[Ocean Sentinels](https://github.com/Gowshik-S/Ocean-Sentinels)** — Coastal safety and hazard reporting platform (SIH 2025, internal round cleared). Offline-first via BLE mesh relay so alerts still propagate without connectivity.
`FastAPI` `PostgreSQL` `Redis` `S3` `Mapbox GL JS` `Kotlin / Jetpack Compose` · [Live](https://sih.gowshik.in)

**E-waste pickup & refurbishment platform** — AI-assisted platform for pickup routing and device refurbishment triage, built for research paper submission.
`FastAPI` `MobileNetV2 + XGBoost` `SHAP` `OR-Tools VRP`
